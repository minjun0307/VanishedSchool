# 작업 규칙 (필수 준수)

이 문서의 규칙은 **Claude를 실행한 모든 세션에서 항상 적용**되며, 예외 없이 지켜야 합니다.

## 1. 언어 — 항상 한국어

- 대화, 설명, 요약, 질문, 완료 보고 등 **사용자에게 보이는 모든 텍스트는 한국어**로 작성합니다.
- 코드 자체(변수명·함수명 등)와 이미 영어로 작성된 기존 주석은 그대로 두되, **새로 다는 주석과 커밋 메시지는 한국어**로 씁니다.
- 영어로 답하지 않습니다. 영어로 된 도구 출력이나 에러 메시지를 인용할 때는 한국어 설명을 함께 붙입니다.

## 2. 지시한 범위만 작업

- **시키지 않은 작업을 임의로 진행하지 않습니다.** 요청한 파일·기능 외의 코드를 마음대로 고치거나, 리팩터링하거나, 삭제하지 않습니다.
- 더 나은 방법이 보이면 **제안·건의는 가능**합니다. 다만 제안만 하고, 사용자가 승인하기 전에는 실행하지 않습니다.
- 작업하거나 제안할 때는 **그 로직이 무슨 일을 하는지 구체적이고 쉽게 설명**합니다.
  - 무엇을 → 왜 → 어떤 순서로 동작하는지
  - 전문 용어는 풀어서, 초보자도 이해할 수 있는 수준으로
  - "이 함수는 A를 받아서 B로 바꾼 뒤 C에 넣습니다" 처럼 흐름이 보이게
- 요청이 모호하면 혼자 추측해서 진행하지 말고 **먼저 물어봅니다.**

## 3. 코드 작성 후 반드시 검토·수정

- 코드를 쓰고 바로 끝내지 않습니다. **작성 → 직접 다시 읽고 검토 → 문제 발견 시 수정** 순서를 지킵니다.
- 검토 시 확인할 것:
  - 요청한 동작을 실제로 하는가 (요구사항 누락 없는지)
  - null 참조, 배열 인덱스 범위, 예외 상황 처리
  - 기존 코드 스타일·네이밍 규칙과 일치하는가
  - 내 변경 때문에 쓰이지 않게 된 변수·함수·using 문이 남아 있지 않은가
- 검토 결과를 사용자에게 **한국어로 요약 보고**합니다. 문제가 있었으면 무엇을 어떻게 고쳤는지 밝힙니다.
- 확인하지 못한 부분은 "확인함"이라고 말하지 않고, **검증하지 못했다고 솔직히** 말합니다.

## 4. 코드 최적화를 고려해서 작성

- 코드를 쓸 때는 **동작만 맞추고 끝내지 않고, 성능(최적화)까지 같이 생각**합니다. 특히 이 프로젝트는 Unity 게임이라 매 프레임 도는 코드가 많으므로 아래를 지킵니다.
- **매 프레임 호출되는 곳(Update / FixedUpdate / LateUpdate / 코루틴 루프)** 에서는:
  - `GetComponent`, `FindObjectOfType`, `Camera.main`, `GameObject.Find` 같은 **탐색 함수를 매번 호출하지 않습니다.** `Awake`/`Start`에서 한 번 찾아 변수에 저장(캐싱)해 두고 재사용합니다.
  - `new` 로 객체·리스트·배열을 매 프레임 만들지 않습니다. 총알·이펙트처럼 자주 생성/파괴되는 오브젝트는 **오브젝트 풀링**을 고려하고, 필요하면 먼저 제안합니다.
  - 문자열 이어붙이기(`+`), `foreach` 로 인한 불필요한 할당 등 **GC(가비지 컬렉션)를 유발하는 코드**를 줄입니다. GC가 몰리면 순간적으로 프레임이 끊깁니다.
  - 거리 비교는 `Vector3.Distance` 대신 `sqrMagnitude` 비교를 쓰는 식으로, **제곱근 같은 무거운 연산을 피할 수 있으면 피합니다.**
- **불필요한 반복을 줄입니다.** 같은 값을 여러 번 계산하면 지역 변수에 담아 재사용하고, 반복문 안에서 매번 다시 구할 필요 없는 값은 반복문 밖으로 뺍니다.
- **조기 탈출(early return)** 로 필요 없는 계산을 건너뜁니다. 조건이 안 맞으면 뒤 로직을 아예 실행하지 않게 만듭니다.
- 다만 **가독성을 해치는 과한 최적화는 하지 않습니다.** 실제로 자주 실행되는 구간(핫 패스)만 최적화하고, 어쩌다 한 번 도는 코드는 읽기 쉬운 쪽을 택합니다. 최적화와 단순함이 충돌하면 **어느 쪽이 나은지 이유를 설명하고 사용자에게 물어봅니다.**
- 최적화를 적용했다면 **어디를, 왜, 어떻게 바꿨고 무엇이 좋아지는지**를 3번 규칙의 검토 보고에 함께 한국어로 적습니다.
